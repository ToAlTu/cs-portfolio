# pwn.college Coursework

This folder documents my completed work from [pwn.college](https://pwn.college), a cybersecurity education platform developed by researchers at Arizona State University.

I completed three modules independently, with no prior background in systems programming, cryptography, or web security. Each module uses a hands-on, challenge-based format where you solve progressively harder problems to advance.

## Modules Completed

| Module | Levels Completed | Focus Area |
|---|---|---|
| [Baby Server](./baby-server/) | 11 | x86-64 assembly, Linux syscalls, HTTP, networking |
| [Baby Crypto](./baby-crypto/) | 14 | Cryptographic attacks, RSA, AES, Diffie-Hellman, TLS |
| [Baby Web](./baby-web/) | 12 | Web exploitation, SQL injection, XSS, SSRF |

## Why This Work Matters

These modules go well beyond typical coursework. Rather than using libraries or frameworks, every solution required working directly with the underlying system — raw syscalls in assembly, mathematical cryptographic operations in Python, and manual HTTP requests for web exploitation.

The skills developed here directly apply to debugging complex systems, understanding security vulnerabilities, and reasoning about how software fails — all of which are critical in backend engineering and AI systems work.

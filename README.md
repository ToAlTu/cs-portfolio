### 🔐 Security & Systems — pwn.college Coursework
Independent coursework completed on [pwn.college](https://pwn.college), a cybersecurity platform developed by ASU researchers. I completed three modules with no prior background in any of the areas covered.

| Module | What I Built / Learned |
|---|---|
| [Baby Server](./pwn-college/baby-server/) | HTTP server from scratch in x86-64 assembly using raw Linux syscalls |
| [Baby Crypto](./pwn-college/baby-crypto/) | Cryptographic attacks, RSA, AES, Diffie-Hellman, and a full TLS-like protocol |
| [Baby Web](./pwn-college/baby-web/) | Web exploitation — SQL injection, XSS, and SSRF |

Each module folder contains a README documenting the thought process behind key challenges rather than solutions, in keeping with pwn.college's learning-first philosophy.
